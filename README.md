# corpus-edit — 정책보고서 교열 기준

보건복지·사회정책 분야 정책보고서와 공문서를 교열하기 위한 **어문 규범 기준과 항목 사전**.
기계가 읽도록 만들어졌다. 웹 채팅형 AI에 URL로 물리거나, 교열 도구가 내려받아 쓴다.

판 식별자: `KB-20260911_v4_ALL_CASES`

---

## 1. 구성 — 읽는 주체가 다르면 크기 제약도 다르다

| | 누가 읽나 | 크기 제약 | 무엇 |
|---|---|---|---|
| **규칙** `*.md` | **AI 모델**이 URL로 | **있다.** fetch가 앞부분만 가져오므로 잘게 쪼갬 | 문맥 판단이 필요한 규칙 |
| **사전** `dict.json` | **교열 도구**가 | **없다.** 브라우저가 통째로 받음 | 낱말 대조표 |

낱말 대조표(`갯수`→`개수`)는 모델에게 물을 이유가 없다. 도구가 직접 찾아 고치는 편이
정확하고 빠르다. 모델에게는 문맥이 갈라야 하는 것만 맡긴다.

`index.md` 는 사람용 목차다. 모델에게 목차를 읽혀 스스로 고르게 하면 fetch가 2단이 되어
지연과 실패가 배가 된다. **어느 샤드를 쓸지는 도구가 로컬에서 정한다.**

## 3. 항목 사전 `dict.json`

| 갈래 | 건수 | 쓰임 |
|---|---|---|
| `치환` | 474 | 자격 심사를 통과한 것. 도구가 바로 고친다 |
| `판별` | 130 | 문맥이 갈라야 하는 대립축(지양/지향). 걸린 행만 모델에 붙인다 |
| `보존` | 80 | **고치면 안 되는 올바른 표기.** 과잉 교정을 막는다 |
| `권고` | 59 | 순화어·차별표현. 교열이 아니므로 자동 적용하지 않는다 |
| `탈락` | 385 | 규칙이 담당하거나 자격 미달. 치환에 쓰지 않는다 |

`치환`은 "정정형이 오류형의 **같은 자리 고침**"일 때만 들어간다 — 띄어쓰기만 다르거나
글자 편집 거리가 2 이하일 때. 정정형에 원문에 없는 낱말이 붙은 행은 전부 떨어진다.

## 4. 읽었는지 확인하는 법

샤드마다 머리에 **확인낱말**이 있다. 파일 안에만 있는 값이라, 모델이 주소를 읽지 않으면 맞힐 수 없다.

```
판: KB-20260911_v4_ALL_CASES
샤드: core
확인낱말: 솔방울
```

교열을 시킬 때 이렇게 묻는다.

```
[확인] 읽은 파일의 '확인낱말' 값을 헤더 다음 줄에 그대로 적어라. 읽지 못했으면 "기준 없음".
```

`manifest.json` 에 전체 정답이 있어 도구가 자동 대조할 수 있다.

## 5. 주소

판 번호를 붙인 주소를 쓴다. 브랜치 주소(`/main/`)는 캐시가 최대 5분이라
방금 고친 기준이 반영되지 않은 채 교열될 수 있다.

```
https://raw.githubusercontent.com/beaver21c/corpus-edit/kb-v1.0.0/core.md
```

## 6. probe.md

모델이 URL에서 **몇 자까지 읽어 오는지** 재는 측정용 문서다(교열에는 쓰지 않는다).
2,000자마다 표식이 있고, 모델이 답한 마지막 표식 번호에 2,000을 곱한 값이
실제로 읽어 들인 분량이다. 정답표는 `manifest.json` 에 있다.
