# 조사 · 두음법칙 · 사이시옷 · 준말

### 2-3. 조사

**근거 수준**: 받침 호응은 국어 문법의 기본 규칙 [1차 확인 불요]. '에/에게' 구분은 국립국어원 문법 설명에 근거 [논리적 추론].

#### 2-3-1. 앞말 받침에 맞춘다

받침 있음 → 은 / 이 / 을 / 과 / 으로 / 이나 / 이며 / 이라 · 받침 없음 → 는 / 가 / 를 / 와 / 로 / 나 / 며 / 라 · 'ㄹ' 받침 → 로(으로 아님)

| 틀림 | 바름 |
|---|---|
| 사업를 · 사업가 · 사업는 | 사업을 · 사업이 · 사업은 |
| 결과을 · 결과이 · 결과은 | 결과를 · 결과가 · 결과는 |
| 기준로 · 기준와 | 기준으로 · 기준과 |
| 학생로서 · 현장로부터 · 방법로써 | 학생으로서 · 현장으로부터 · 방법으로써 |
| 시설으로 · 서울으로 · 제도의 개선으로(바름) | 시설로 · 서울로 |
| 지역이나 · 기관나 | 지역이나 · 기관이나 |
| 보건복지부며 | 보건복지부며 (부: 모음 → 며, 바름) |

#### 2-3-2. 외래어·영문 약어·숫자·괄호 뒤

- 조사는 **읽는 소리**의 받침에 맞춘다. 'WHO는', 'OECD가', 'KIHASA는', 'AI가', 'GDP는', '30%가'(퍼센트), '2026년은', '1만 명이', '3개소가'.
- 괄호 병기가 있으면 괄호 안은 없는 것으로 보고 **괄호 앞 한글**에 맞춘다: '세계보건기구(WHO)는', '경제협력개발기구(OECD)가', '노인장기요양보험(이하 "장기요양보험")은'.
- 조사는 괄호에 붙여 쓴다: '세계보건기구(WHO) 는' → '세계보건기구(WHO)는'.

#### 2-3-3. '에'와 '에게'

- 사람·동물(유정 명사) 뒤에는 '에게', 사물·기관·단체·지역(무정 명사) 뒤에는 '에'.

| 틀림 | 바름 |
|---|---|
| 정부에게 · 기관에게 · 지자체에게 · 학교에게 · 병원에게 · 시설에게 · 사업단에게 | 정부에 · 기관에 · 지자체에 · 학교에 · 병원에 · 시설에 · 사업단에 |
| 수급자에게 · 이용자에게 · 종사자에게 | (바름) |

※ 단체를 사람처럼 의인화한 문맥(예: 인용문)은 두고 본다.

#### 2-3-4. 손대지 않는 조사 문제(문체 영역, C등급)

'의' 남용('연구의 결과의 분석'), '~에 대한/~에 관한' 남용, '~에 있어(서)', '~로 인하여', '~에 의하여', '~로부터'(출처 뜻), 개조식에서의 조사 생략('사업 추진', '예산 확보')은 모두 문체 문제이므로 보고하지 않는다.

### 5-1. 두음법칙을 잘못 적용하는 경우

| 겉모습 | 함정 | 바른 판정 |
|---|---|---|
| 발열(發熱) · 작열감(灼熱感) · 가열 · 과열 · 백열 | '열'이므로 '렬→열'인가? | 본디 '열(熱)'이지 '렬'이 아님. 두음법칙 대상 아님. 발열·작열감이 바름 |
| 저렴(低廉) · 청렴(淸廉) · 분류(分類) · 종류(種類) · 진료(診療) · 치료(治療) · 급료(給料) · 재료(材料) · 자료(資料) | 'ㄹ' 소리가 둘째 음절이면 '여/유/요'로? | 제11항 붙임1은 '렬·률'만 다룸. '렴·류·료'는 본음 그대로 |
| 출산율·이환율·규율·비율·백분율·실패율·환율·선율 | 뒤에 '률'이 원형이니 항상 '률'? | 앞 글자가 모음·ㄴ 받침이면 '율'(2-2-2). 다만 '전율(戰慄)'은 '전율'이 표준(ㄴ 받침) |
| 열렬(熱烈) · 격렬(激烈) · 강렬(强烈) · 극렬(極烈) | '열렬'은 '열열'? | 첫 음절 '열'은 두음법칙(列→열이 아니라 熱), 둘째 '렬(烈)'은 ㄹ 받침 뒤이므로 '렬' 유지 → 열렬. 격렬·강렬(ㄱ·ㅇ 받침) 유지 |
| 나열(羅列) · 배열(配列) · 진열(陳列) · 분열(分裂) · 균열(龜裂) · 결렬(決裂) | 균열/균렬? | 모음·ㄴ 뒤 → 열(나열·배열·균열·분열). ㄹ 받침 뒤 → 렬(결렬) |
| 연도(年度) · 년도 | '2026년도'는 '2026연도'? | 독립 명사 '연도'는 두음법칙(회계 연도). 숫자·관형어 뒤 '년도'는 의존적 결합으로 '년도'(2026년도) — 「한글 맞춤법」 제10항 붙임의 원리. '연도별'은 '연도별' |
| 연간(年間) · 년간 | '3년간'은 '3연간'? | 단위성 의존명사로 쓰일 때 '년간'(3년간). 독립 명사 '연간 소득' |
| 이율(利率) · 요율(料率) · 세율(稅率) · 배율(倍率) | 원형이 '률'이니 '이률'? | 모음 뒤 → 율 |
| 파열(破裂) · 열상(裂傷) | 열상? 렬상? | 첫 음절은 두음법칙 → 열상. 둘째 음절 모음 뒤 → 파열 |
| 남녀(男女) · 여성(女性) · 자녀(子女) · 소녀 | 남녀는 '남여'? | 둘째 음절 이하는 본음 '녀' 유지(남녀·자녀). 첫 음절만 '여'(여성) |
| 신여성(新女性) · 공염불(空念佛) · 해외여행 · 국제연합 | 신녀성? 공념불? | 접두사처럼 쓰이는 한자어 뒤나 합성어 둘째 요소가 독립 단어이면 두음법칙 적용(제10항 붙임2·제11항 붙임4) → 신여성·공염불·해외여행·국제연합 |
| 역사(歷史) · 이역(異域) · 경력(經歷) · 열역학 | 이력서? 이역서? | '경력'(둘째 음절 본음). '이력서(履歷書)' — 둘째 음절 '력' 유지. '열역학(熱力學)'은 합성어 둘째 요소 '역학'이 독립 단어 → 열역학 |

### 5-2. 사이시옷을 잘못 적용하는 경우

| 겉모습 | 함정 | 바른 판정 |
|---|---|---|
| 개수(個數) · 초점(焦點) · 대가(代價) · 시가(市價) · 소수점(小數點) · 화병(火病) · 전세방(傳貰房) | 뒷말 첫소리가 된소리로 나니 사이시옷? | 한자어+한자어 합성은 예외 6개(곳간·셋방·숫자·찻간·툇간·횟수)를 빼고 사이시옷 없음 |
| 예상값 · 평균값 · 측정값 · 절댓값 · 최댓값 · 대푯값 · 기댓값 · 근삿값 | 한자어+'값'인데? | '값'은 고유어. 앞말이 모음으로 끝나고 뒷말 첫소리가 된소리 → 사이시옷(절댓값·최댓값·대푯값·기댓값·근삿값). 앞말이 받침으로 끝나면 사이시옷 자리가 없음(예상값·평균값·측정값) |
| 뒤풀이 · 위층 · 뒤편 · 아래층 · 뒤쪽 | 뒷풀이? 윗층? | 뒷말 첫소리가 거센소리·된소리이면 사이시옷 안 붙임(위층·뒤풀이·뒤쪽·뒤편은 'ㅍ' 거센소리) |
| 머리말 · 인사말 · 예사말 · 소개말 · 반대말 · 존댓말 · 혼잣말 · 노랫말 | 머릿말? | 'ㄴ' 소리가 덧나는지에 따름 — 머리말·인사말·예사말·소개말·반대말은 사이시옷 없음, 존댓말·혼잣말·노랫말은 있음(표준 발음 기준) [미확인: 개별 단어] |
| 장맛비 · 등굣길 · 하굣길 · 만둣국 · 순댓국 · 북엇국 | 한자어가 섞였는데? | 한자어+고유어 합성이면 사이시옷 대상(장맛비·등굣길·만둣국). 한자어+한자어만 제외 |
| 개수·건수·횟수 | 셋 다 한자어(個數·件數·回數)인데 횟수만? | 횟수(回數)는 예외 6개 중 하나. 개수·건수는 사이시옷 없음 |
| 핑크빛 · 피자집 · 오렌지주스 · 데이터양 | 외래어 뒤에 사이시옷? | 외래어가 든 합성어에는 사이시옷을 쓰지 않음(핑큿빛 X, 피잣집 X). 제30항은 고유어·한자어 합성만 대상 [논리적 추론] |
| 강조를 위해 저자가 일부러 '갯수'라 쓴 경우 | 되돌릴까? | 규범상 '개수'. 인용문 안이 아니면 고침. 저자 의도가 명백한 강조 표기('갯수'로 따옴표 안에 넣음)는 인용문으로 취급 |

### 5-3. 준말·소리 규칙의 함정

| 겉모습 | 함정 | 바른 판정 |
|---|---|---|
| 필수(必須) · 별수 · 실수(失手) · 수수료(手數料) | '수' 앞이 받침이니 '숫'? | 사이시옷과 무관. '별수 없다'는 한 단어 '별수'(사전 등재) [논리적 추론] |
| 집중(集中) · 신중(愼重) · 도중(途中) · 그중 · 이 중 | '중'은 의존명사니 띄움? | 집중·신중·도중·그중은 한 단어. '이 중(둘 중)'은 띄움(2-4-2) |
| 비고란(備考欄) · 성명란(姓名欄) · 독자란 · 어린이난 · 가십난 | 두음법칙으로 '난'? | '란(欄)'은 한자어 뒤에서 '란'(비고란·성명란·독자란), 고유어·외래어 뒤에서 '난'(어린이난·가십난) — 제11항 붙임의 원리 |
| 하지 말라고 · 하지 마라 · 하지 마 | 'ㄹ' 어간이니 '말라고'? | 간접 인용 '말라고'(하지 말라고 하였다), 직접 명령 '마라/마'. 개조식·서술문의 '~하지 말 것'은 '말'. 둘 다 규범 안 |
| 믿음으로 · 만듦으로써 · 함으로써 / 하므로 | '-ㅁ으로(써)'와 '-므로' | 명사형+조사 '-ㅁ으로써'는 수단('노력함으로써'), 어미 '-므로'는 이유('노력하므로'). 2-2-6 |
| 의의(意義) · 이외(以外) · 수명(壽命) · 한해(旱害) · 정렬(整列)/정열(情熱) · 이중(二重)/이 중 | 오탈자로 보이나 다른 낱말 | 문맥으로 판단. 확신 없으면 보고하지 않음 |
| 부부간 · 형제간 · 부자간 · 모녀간 · 고부간 · 동기간 | '간'은 의존명사니 띄움? | 사전 등재 합성어는 붙임 [미확인: 개별 단어]. 그 밖(기관 간·지역 간·세대 간)은 띄움 |
| 비상시 · 유사시 · 평상시 · 필요시 | '시'는 의존명사니 띄움? | 비상시·유사시·평상시는 한 단어 [미확인: '필요시' 등재 여부]. 그 밖('신청 시', '위반 시')은 띄움 |
| 알려지다 · 이루어지다 · 밝혀지다 · 만들어지다 | '-어지다'가 붙었으니 이중 피동? | 단순 피동 접미사가 없는 '알리다+어지다', '이루다+어지다'이므로 이중 피동 아님. '보여지다·잊혀지다·불리워지다·나뉘어지다'만 이중 피동(2-1) |
| 불리다 · 여겨지다 · 되어지다 | '되어지다'는? | '되어지다'는 이중 피동 계열 → '되다'. '불리다'는 단순 피동(○) |
| 잊혀진 계절 · 잊혀지지 않는 | 굳어진 관용 표현인데? | 규범상 '잊힌·잊히지'. 인용문·제목(고유명사) 안이면 그대로, 본문이면 고침 |
| 맞추다/맞히다 · 늘이다/늘리다 · 벌이다/벌리다 · 부치다/붙이다 · 저리다/절이다 · 썩이다/썩히다 · 삭이다/삭히다 | 소리가 같음 | 2-2-6 판별표. 문맥이 한쪽으로만 읽힐 때만 고침 |
| 며칠 · 몇 일 | '몇 일'이 맞을 것 같음 | 항상 '며칠'(표준어 규정). '몇 일'은 어떤 문맥에서도 틀림 |
| 오랜만 · 오랫동안 · 오랜 | 오랜만/오랫만? | '오랜만'(오래간만), '오랫동안'(사이시옷 ○). '오랜 숙원'은 겹말(2-6) |
| 설거지 · 설겆이 | 원형은 '설겆다'? | '설거지'가 표준(어원 의식 소멸) |
| 삼가다 · 삼가하다 | '삼가해 주시기' | '삼가다'가 기본형 → '삼가 주시기'. 개조식 '흡연 삼가' |
| 안절부절못하다 · 안절부절하다 | '안절부절하다'가 자연스러움 | '안절부절못하다'만 표준 |
| 개발새발 · 괴발개발 | 둘 중 하나만? | 둘 다 표준(2011 복수 표준어) [미확인] |
| 데이터양 · 데이터량 · 정보량 · 노동량 · 강우량 · 알칼리양 | '량'은 항상 '량'? | 한자어 뒤 '량'(정보량·노동량·강우량), 고유어·외래어 뒤 '양'(데이터양·구름양·알칼리양·에너지양) — 제11항 붙임의 원리 |
| 웬일 · 왠지 · 웬만하다 | 왠/웬 | '왠지'만 '왠'(왜인지). 그 밖은 모두 '웬'(웬일·웬만하다·웬걸) |
| 뒤처지다 · 뒤쳐지다 | 처/쳐 | '뒤처지다'(뒤에 처지다). '뒤쳐지다'는 '뒤집혀 젖혀지다' |
| 금세 · 금새 | 금새? | '금세'(금시에) |
| 역할 · 역활 | 역활? | '역할'만 바름 |
| 어떡해 · 어떻게 | 뜻이 다름 | '어떡해'는 '어떻게 해'의 준말(서술어), '어떻게'는 부사. 보고서 문체에는 '어떻게'만 나옴 |
